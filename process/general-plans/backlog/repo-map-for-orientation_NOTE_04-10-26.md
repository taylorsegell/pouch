# Repository map for orientation ("repo atlas")

**Status:** OUT OF SCOPE. Not scheduled; excluded from every phase. Tracked only so it is not lost.

**Summary:** a map of a repository's files and symbols served to the agent so it spends fewer calls orienting.

**Do not confuse** with the product Phase 3 atlas (PRD RTE-2), which maps paths and topics to skills. The brief states this one is not that atlas and not part of any phase.

## Why deferred

Brief "Out of scope" excludes it from all phases; ADR-0001 lists it as a related idea, not a commitment.
